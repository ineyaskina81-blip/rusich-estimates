# rusich-estimates

Интерактивный прототип системы смет ООО «ИСК Русич». Данные демонстрационных смет вымышлены.

## Как открыть

На GitHub переключитесь на ветку `prototype/estimate-workflow`, нажмите **Code → Download ZIP**, распакуйте архив и откройте `index.html` в браузере. Установка и подключение к серверу не нужны.

## Как создать смету

В реестре нажмите **+ Новая смета**, укажите объект и при необходимости заказчика и виды работ. После нажатия **Создать смету** откроется пустая карточка с присвоенным номером. Под таблицей заполните форму **Новая расценка** и нажмите **Добавить расценку**. Объёмы вводятся вручную. Все этапы можно пройти самостоятельно в одной вкладке.

Сметы и позиции сохраняются локально в браузере. Открывайте тот же файл в том же браузере и профиле. Если локальное хранилище недоступно, данные доступны до обновления или закрытия страницы.

## Как заполнить разделы сметы

Названия разделов и подразделов вводятся вручную. Кнопка **+ Раздел** добавляет раздел в конец. Чтобы выбрать другое место, воспользуйтесь кнопкой **Вставить раздел в начало** или **Вставить после** рядом с нужной позицией. Для подраздела выберите родительский раздел. Строки после точки вставки в текущей группе переходят под новый заголовок. Если раздел разбит внутри подраздела, обе части сохраняют название подраздела.

Строка **Итого по разделу** суммирует все позиции этого раздела, включая подразделы. Она использует цену из справочника до подтверждения и цену заказчику после подтверждения, без добавления НДС из общего итога. Если часть строк скрыта фильтрами, показывается итог за весь раздел.

При удалении подраздела позиции переходят в его родительский раздел. При удалении раздела позиции попадают в **Без раздела**. Добавлять и удалять разделы можно на любом этапе. На этапе ПТО кнопка **Добавить сюда** под заголовком выбирает нужный раздел для новых строк. Позицию можно изменить или удалить кнопками рядом с её названием.

## Как использовать справочник расценок

1. Вверху страницы нажмите **Загрузить справочник** и выберите `Справочник_расценок_Русич.xlsx`. Книга читается в браузере. Чтобы применить новую редакцию Excel, нажмите **Обновить справочник**.
2. В форме под таблицей начните вводить название или код в поле поиска. Выберите позицию из выпадающих подсказок с ценой. Название, раздел и единица измерения заполнятся. Введите объём и нажмите **Добавить расценку**. Для следующего этапа откройте добавленную строку.
3. Выберите позицию и цену из справочника, введите объём и нажмите **Добавить расценку**. Повторите для всех строк. Для техники цена из справочника служит основой для цены заказчику, закупочный тариф подтверждает ОМТС отдельно.

## Как передать смету по этапам

1. **ПТО** заполняет все позиции и объёмы, затем передаёт смету целиком кнопкой в блоке «Этап сметы».
2. **ОМТС** открывает строки машин и механизмов, проверяет и подтверждает закупочные тарифы. После последней проверки передаёт смету главному инженеру.
3. **Главный инженер** проверяет объёмы техники и при необходимости корректирует их. Для часового тарифа объём в строке равен подтверждённым часам. После проверки всех строк передаёт смету коммерческому директору.
4. **Коммерческий директор** подтверждает или корректирует цену для заказчика по каждой позиции. Исходная цена из справочника остаётся в карточке.

Смета без машин и механизмов переходит из ПТО прямо коммерческому директору.

На этапе ПТО нажмите **Удалить** рядом с нужной позицией. После подтверждения строка исчезнет из сметы, итоги пересчитаются.

## Что проверить

Создайте смету, добавьте работу и механизм и передайте смету из ПТО в ОМТС. Подтвердите закупочную цену механизма, затем передайте смету главному инженеру. Проверьте объём и часы. После передачи коммерческому директору подтвердите цену работы и скорректируйте цену механизма. Проверьте сумму по каждой строке и статус сметы **Готова**.

Все этапы доступны в одной демонстрационной сессии. При доступном локальном хранилище изменения сохраняются в текущем браузере.
